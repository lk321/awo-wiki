## The hook: the Oni of the Shrine

<Sprite key="oni" scale={3} caption="The Oni of the Shrine" />

Every player has **their own Oni**. Each time it falls, a small language model running on the server reads every fight since its last defeat and tunes its style: which attacks it favours, who it hunts, what it resists. It comes back one generation stronger, up to **G20**, with better loot. In a party you fight the leader's.

## What is here

Amazing World Online is a 2D pixel-art MMORPG set in rural Japan, built as a vertical slice: three worlds, thirteen maps, three main bosses that learn, six item rarities and an art pipeline with no assets at all — every sprite, prop, icon and tile is painted in code.
